# Item bank specification (version 1.0.0)

The bank is generated by `src/lib/items/generators/index.ts` and frozen to
`src/data/item-bank.json` by `npm run bank:generate`. It contains **524 items**:

| Domain | Family | Items | Response | Options |
|---|---|---:|---|---:|
| Gf | matrix | 40 | choice | 8 |
| Gf | figure-series | 24 | choice | 8 |
| Gf | deduction | 17 | choice | 4–5 |
| Gv | rotation-2d | 18 | choice | 4 |
| Gv | rotation-3d | 16 | choice | 4 |
| Gv | paper-folding | 14 | choice | 5 |
| Gq | number-series | 26 | numeric (free) | — |
| Gq | balance | 15 | choice | 5 |
| Gq | number-matrix | 12 | numeric (free) | — |
| Gc | vocabulary | 28 | choice | 5 |
| Gc | analogy | 26 | choice | 5 |
| Gc | classification | 16 | choice | 5 |
| Gwm | four span tasks | 56 | sequence | — |
| Gs | symbol search, visual comparison | 192 | binary | 2 |
| — | practice items | 24 | | |

Every item records: id, content version, domain, CHC narrow ability, family,
prompt, stimulus, response specification (key and distractors), explanation,
rule descriptors, a priori difficulty (logit, level, method, features),
estimated time, time limit, generator provenance (name, version, seed) and a
SHA-256 content hash. Ids of adaptive items are assigned after shuffling each
family, so an id carries no information about difficulty. (Span-trial ids
encode the sequence length, which participants see anyway; speed-trial ids
are sequential because every trial is equally easy.)

## Generation and verification per family

### Matrices (Gf, induction)
3×3 figures, bottom-right missing. Attributes: shape, count (1–4), size (3),
fill (white / striped / black), arrow direction (8), line elements (10-element
vocabulary), marker position (8). Rules (Carpenter et al., 1990): constant in
a row, progression (±1; ±2 for direction), distribution of three (Latin
square), arithmetic on count (a + b, a − b), Boolean superimposition (OR, AND,
XOR, A − B).
**Options:** attribute-bisection tree (Hu et al., 2021): three attributes take
the correct or one plausible wrong value; 2³ = 8 options, each attribute value
in exactly half of them.
**Verification:** `solvers/matrixSolver.ts` infers rules row- *and*
column-wise from a superset library (including rules the generator never uses,
such as multiplication and B − A) and rejects the item if any attribute has no
rule, if consistent rules disagree, or if not exactly one option matches.

### Figure series (Gf, induction)
Six panels, choose the seventh. Rules per attribute: constant, cyclic
progression (step 1–3), alternation, period-3 repetition, interleaved
progressions, accelerating progression. Same option design.
**Verification:** `solvers/seriesSolver.ts` (superset library, unique
prediction, unique match).

### Deduction (Gf, general sequential reasoning)
Linear orderings of 3–5 labelled objects (including partial orders with
"which statement must be true?"), categorical syllogisms over invented nouns
(to remove belief bias), and conditional reasoning about cards (modus ponens,
disjunctive syllogism, modus tollens, chained modus tollens, "unless", and
the invalid forms affirming the consequent / denying the antecedent).
**Verification:** `solvers/logic.ts` — enumeration of all consistent orders,
all non-empty-region models of a three-set Venn diagram (with existential
import, stated in the item), and full truth tables. The logical form is stored
in `item.verification` and re-proven by the tests.

### Mental rotation (Gv)
2D: chiral polyominoes (5–9 cells) without rotational symmetry. 3D:
Shepard–Metzler-style polycubes (8–12 cubes in four arms), isometric
projection, every cube at least 25% visible in every view.
**Options:** two mirror pairs — {rotated target, its mirror image} and
{another shape, its mirror image} — so no option is the odd one out.
**Verification:** canonical forms under C4 (2D) and the 24-element rotation
group (3D); exactly one option is rotation-equivalent to the target.

### Paper folding (Gv)
One to three folds (orthogonal, same-axis or diagonal), one or two punches on
an 8×8 grid. Foils model errors: a fold left unfolded, reflection across the
wrong line, punch shifted by one cell (same symmetry as the key), hole
missing/moved, mirrored pattern. Foils at least as symmetric as the key are
preferred.
**Verification:** exact integer reflection geometry (`paper.ts`).

### Number series (Gq)
Arithmetic, geometric, second-order, interleaved, alternating operations,
Fibonacci-type, geometric differences, affine recurrences, mixed interleaving.
Free numeric response.
**Verification:** `solvers/numberSeriesSolver.ts` fits a library of simple
rules (constant difference/ratio, 2nd/3rd-order differences, geometric
differences, affine and second-order linear recurrences, interleaving,
operation cycles, growing factors); all fits must predict the same next term,
and draws that a simpler rule also explains are rejected.

### Balance problems (Gq)
Pictorial linear equations solved by substitution (2–4 symbols, 1–3 scales).
**Verification:** exact rational Gaussian elimination (`balanceSolver.ts`).
Numeric options are a window of five consecutive values with the key at a
random position.

### Number matrices (Gq)
Rows (or columns) obey one arithmetic relation; the missing cell may be in the
last or the middle column. **Verification:** brute force over 0–999 against a
library of 24 row and column relations; exactly one value may satisfy any.

### Working memory (Gwm)
Digit span forward (3–9) and backward (2–8), digit–letter reordering (2–8;
consonants not confusable with digits), spatial span (3–9, nine blocks in an
original irregular layout). Two trials per length, no repeated elements, no
runs of three consecutive digits.

### Processing speed (Gs)
Symbol search: 24 original glyphs (3–4 strokes on a 3×3 grid, pairwise ≥ 3
strokes apart); targets present in exactly half of the trials; foils chosen to
resemble the targets. Visual comparison: 5–8 character strings; "different"
pairs differ by one visually confusable substitution or one swap.

### Verbal knowledge (Gc)
Hand-written vocabulary, analogy and odd-one-out items. They cannot be machine
proven; tests check structure only. Each needs expert review; a negative
item–rest correlation in pilot data is the usual sign of a miskeyed or
ambiguous verbal item.

## A priori difficulty models

All models output a provisional logit; levels are bands centred on −2…2
(level 1 < −1.5 ≤ level 2 < −0.5 ≤ level 3 < 0.5 ≤ level 4 < 1.5 ≤ level 5).
Weights are expert judgement and must be re-estimated (LLTM) from pilot data.

| Family | Model |
|---|---|
| Matrix | −2.2 + Σ rule weights + 0.35 × (rules − 1); weights: constant-row 0.25, progression 0.6 (±2: 0.8), distribution 0.95, addition 1.2, subtraction 1.35, OR 1.0, A−B 1.6, AND 1.7, XOR 2.2, marker progression 0.6, marker distribution 0.95; +0.1 per line element above 3 |
| Figure series | −2.2 + Σ weights + 0.4 × (rules − 1); cyclic step 1: 0.6, step ≥2: 0.8, alternation 0.5, period 3: 0.7, interleaved 1.5, accelerating 1.6 |
| Ordering | −2.4 + 0.45 × (terms − 3) + 0.25 mixed phrasing + 0.3 scrambled + 0.6 "second" / 1.2 "must be true" + 0.5 partial order + 0.7 negation |
| Syllogism | −1.6 + 0.4 × particular premises + 0.4 × negative premises + 0.5 non-canonical figure + 1.0 no valid conclusion + 0.3 particular conclusion |
| Conditional | MP −2.0, DS −1.2, MT −0.3, DA 0.4, AC 0.6, chained MT 0.7, only-if 0.8, unless 1.2 |
| Rotation 2D | −2.0 + 0.3 × (cells − 5) + 0.3 (180°) or 0.6 (non-right angle) + 0.5 subtle foil |
| Rotation 3D | 0.4 + 0.25 × (cubes − 8) + 0.3 (≥ 10 cubes) + 0.2 (≥ 120°) + 0.3 (180°) |
| Paper folding | −2.0 + 0.9 × (folds − 1) + 0.6 diagonal + 0.35 × (punches − 1) + 0.3 same-axis |
| Number series | per family from −2.1 (small arithmetic) to 1.5 (mixed interleaving); +0.2 if the answer exceeds 200 |
| Balance | direct −1.9, divide −1.2, both sides −0.6, chain −0.2, mixed 0.5, chain-mixed 1.0, four symbols 1.6 |
| Number matrix | sum −1.9 … product with middle cell missing 1.3 |
| Spans | 0.85 × (length − centre); centres 6 (forward), 4.5 (backward, reordering), 5 (spatial) |
| Verbal | expert level (1–5) → logit −2…2, informed by word frequency and relational abstractness |
| Speed | fixed −2.5 (not used for scoring) |

## Versioning policy

- The frozen JSON is the source of truth for administration and calibration.
- `npm run bank:check` (and a unit test) fail if the generators no longer
  reproduce it byte for byte.
- Any change to what a participant sees requires a new content version for the
  affected items (`version` + 1) and a new bank version. Calibration and norm
  data are keyed by `id@version`, so changed items lose their parameters
  until recalibrated.
- Version 1.0.0 has not been administered to anyone; it was regenerated in
  place during development.
